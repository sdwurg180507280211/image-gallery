# 历史图片提示词归档

本目录用于把已经入库的历史图片补充为可复用、可追溯的生成提示词。

## 目录

- `characters/`：人物长期身份与系列母提示词，只记录跨多张图片稳定存在的身份特征与风格边界。
- `assets/`：单张图片对应的完整提示词，可直接复制用于复现或继续创作。

## 提示词类型

- `original`：确实保存下来的原始生成提示词。
- `reconstructed`：根据原始图片、历史 Metadata、人物身份设定和当时的系列上下文重建。它用于复现，不冒充当年的逐字原始输入。

## 网站关联

`data/prompt-index.json` 只保存素材 ID、提示词路径和提示词类型。大图查看时按需加载提示词正文，首页不会加载全部长文本。

## 历史重建原则

1. 优先使用 Git 历史中仍可恢复的 sidecar Metadata。
2. 人物身份使用同系列稳定特征，不从单张临时服装或道具反推身份。
3. 单图提示词保留该图自己的场景、动作、神态、构图和配色。
4. 无法从历史证据确认的细节不标成“原始提示词”。
