# 医药主 KV 16:9 稳定生成提示词

本模板基于项目当前 3 张医药主 KV 的共同构图规律整理，用于持续生成“无标题、可后续叠加文字”的医药主视觉底图。

## 固定构图边界

以画布宽度 W、高度 H 归一化：

- **左侧硬留白区：x = 0%–40%**
  - 作为后续标题、项目名、会议名的安全区域。
  - 禁止出现高对比器官、人物、DNA、城市、强光束、粗线条等视觉主体。
  - 允许极淡的背景渐变、细粒子、微弱光雾，但必须保持“看起来是空的”。
- **中间过渡缓冲区：x = 40%–50%**
  - 只能承接右侧主视觉的淡化边缘。
  - 可有非常轻的粒子、透明曲线、柔光、数据线，但不能形成独立元素。
- **右侧主视觉区：x = 50%–96%，y = 10%–86%**
  - 主器官及主要医学视觉集中在这里。
  - 主器官视觉中心建议位于 **x = 68%–76%，y = 42%–55%**。
  - 主器官必须是画面唯一第一视觉中心，辅助元素围绕其展开，不得左右平均铺满。
  - 右侧边缘允许少量元素延伸至 96%，但不要贴死画布边缘。
- **下侧变化区：x = 45%–100%，y = 72%–100%**
  - 用于制造不同 KV 之间的变化，但只能作为次级叙事。
  - 下侧元素从右下向主器官汇聚或向左逐渐淡出，禁止形成横贯全宽的厚重地台。
  - 左下区域仍需克制，不能破坏左侧整体留白。

### 当前 1672 × 941 参考坐标

- 左侧硬留白：x ≈ 0–669 px
- 过渡缓冲：x ≈ 669–836 px
- 右侧主视觉：x ≈ 836–1605 px，y ≈ 94–809 px
- 主器官中心建议：x ≈ 1137–1271 px，y ≈ 395–518 px
- 下侧变化区：x ≈ 752–1672 px，y ≈ 678–941 px

这些像素值仅用于当前三张 1672 × 941 KV 的理解；真正生成时始终以百分比边界为准。

## 下侧变化规则

每次生成只选择一种下侧语言作为主要变化，不要同时堆满：

1. **抽象医疗科技型**：半透明能量弧、数据流、光带、ECG 轨迹、粒子曲面。
2. **医学分子型**：DNA、分子网络、细胞结构、网格地台、微弱数据节点。
3. **生活叙事型**：低对比城市剪影、家庭/患者群体、健康生活场景，与主器官形成“医学 + 生活”关系。

共同要求：低对比、半透明、层级低于主器官，不制造第二视觉中心；底部元素不能大面积进入左侧 40% 硬留白区。

## 稳定提示词模板

```text
生成一张高分辨率 16:9 医药项目主 KV 底图，不包含任何标题、文字、logo、水印、按钮或排版占位符。整体为高级医学视觉、现代临床科技感、真实精致的 3D/半透明材质与柔和能量光效，画面干净，有明确视觉层级，适合作为后续 PPT、海报、会议 KV 的无文字底板。

【固定构图】
严格采用“左侧大留白 + 右侧集中主视觉 + 右下可变叙事”的非对称构图。

1. 左侧 0%–40% 宽度必须保持真正的大面积负空间，作为未来标题区。这里禁止出现任何高对比器官、人物、DNA、城市、粗线、强光斑或重要装饰；只允许极淡的背景渐变、微粒、薄雾，让左侧整体看起来安静、干净、可直接叠加大标题和副标题。

2. 画面宽度 40%–50% 为柔和过渡区，只允许右侧视觉自然衰减过来的低透明度粒子、细线、柔光、透明曲线，不得形成独立视觉元素。

3. 所有核心医学主视觉集中在右侧 50%–96% 区域，高度主要控制在画面 10%–86% 内。主器官为【主器官】，是唯一第一视觉中心；其视觉中心位于画面宽度约 68%–76%、高度约 42%–55%，尺寸足够醒目但不要挤满右半边。辅助医学元素【辅助元素】围绕主器官形成前后层次、环绕关系和视觉流动，不能左右均匀铺开，也不能越过左侧留白边界。

4. 右下 45%–100% 宽度、72%–100% 高度为可变叙事区。本次采用【下侧变化】。下侧元素必须低对比、半透明、次级、轻量，从右下向主器官汇聚或逐渐向左淡出，不形成第二视觉中心，不做厚重横向底座，不让底部装饰铺满整张画布，左下仍保持安静。

【视觉风格】
主色为【主色】，以白色/浅色空间作为呼吸区；主器官使用高质量医学 3D、玻璃/晶体/能量材质、细腻体积光、精致粒子和微弱数据结构。可以加入少量蓝紫、粉紫、青色或暖色医学高光，但主色关系必须统一。层次从右侧主器官最清晰、最亮、最高对比，向左逐步降低对比度和细节密度。

【必须遵守】
- 16:9 横版，优先 3840×2160 或当前模型可输出的最高原生分辨率。
- 无任何文字、字母、数字、logo、水印。
- 左侧 40% 大面积留白必须稳定存在。
- 主视觉不得居中，不得铺满整张画面。
- 不做左右对称构图。
- 不把多个器官做成同等视觉权重；只突出【主器官】。
- 下侧变化只做辅助叙事，不抢主视觉。
- 整体要像成熟医药品牌会议 KV，而不是科普插画、信息图或素材堆砌。
```

## 变量填写

只需要替换 4 个变量：

- `【主器官】`：心脏 / 大脑 / 肾脏 / 肝脏 / 肺 / 胃 / 胰腺 / 血管 / DNA 等
- `【主色】`：蓝白 / 蓝紫 / 粉紫 / 青蓝 / 绿色 / 暖橙等
- `【辅助元素】`：建议 1–3 项，例如 DNA、分子、细胞、血管、ECG、数据粒子
- `【下侧变化】`：抽象能量数据流 / DNA 分子网络地台 / 城市与家庭健康叙事，三选一为主

## 使用原则

这个模板固定的是 **空间结构**，不是固定某一张图的内容。后续可以自由更换器官、颜色、辅助元素、材质和下侧叙事，但不要改变“左 40% 留白、40%–50% 过渡、右 50%–96% 主视觉、右下 72%–100% 变化”的基本空间关系。
