# 医药主 KV 16:9 底板母提示词

本文件是项目当前唯一的医药主 KV 底板生成规范。规则来源于上传 ZIP 中约 20 张成熟医药会议 KV 的共同视觉语言，只学习 **底板风格、视觉层级、构图关系和医学元素表达**，不学习其中已有标题、logo、品牌字样、会议信息或文案排版。

目标不是复刻某一张参考图，而是稳定生成同一类成熟的 **医药品牌会议 KV 底板**。

---

## 1. 核心视觉定位

生成结果应当首先像“成熟医药品牌会议 KV 的无文字底板”，而不是：

- 科普插画
- 信息图
- 医学教材配图
- 普通 3D 器官渲染
- 医学元素素材拼贴
- 复杂完整场景插画
- 过度赛博朋克海报

统一追求：

**专业、医学、现代、可信、精致、品牌化、轻科技、可直接后续叠加标题。**

---

## 2. 底板的共同设计语言

### 2.1 医学主体

画面优先围绕 **1 个主医学主体** 建立第一视觉中心。

可选主体包括：

- 心脏
- 大脑
- 肾脏
- 肝脏
- 肺
- 胃
- 胰腺
- 血管
- DNA / 基因
- 神经元
- 关节
- 医学护盾 / 医疗科技核心装置

主体建议采用以下一种或混合表达：

- 半透明 3D 医学模型
- 玻璃质感
- 晶体质感
- 柔和发光轮廓
- 线框医学结构
- 轻医学 UI 结构

医学主体要精致、可信，但不要血腥，不要做硬核解剖图。

如果存在多个器官，必须有明确主次，不能让多个器官拥有同等尺寸、亮度和视觉权重。

### 2.2 辅助医学元素

辅助元素建议控制在 **2–4 类**，用于增强医学语义和空间层次，而不是堆满画面。

可选：

- DNA
- 分子球 / 分子网络
- 细胞
- 血细胞
- 药丸 / 胶囊
- ECG 心电轨迹
- 神经网络
- 医学图标
- 轻数据节点
- 光粒子
- 医学护盾
- 城市 / 家庭 / 患者剪影（仅在需要生活叙事时使用）

辅助元素必须低于主医学主体的视觉层级。

### 2.3 背景

背景采用“大面积低对比底色 + 柔和科技层次”的方式组织。

常用语言：

- 柔和渐变
- 微雾
- 空气感
- 轻波纹
- 纤细流线
- 点阵
- 粒子场
- 微弱网格
- 透明弧面
- 柔光晕
- 能量弧
- 半透明丝带
- 淡山形 / 城市远景

背景可以有细节，但必须满足：

> **近看丰富，远看干净。**

不能把科技感简单理解成大量 HUD 面板、数字框和复杂界面贴图。

### 2.4 动势

这类 KV 的高级感很大程度来自“流动关系”。

优先使用：

- S 形流线
- 环抱式能量轨迹
- 弧形光带
- 丝带状曲面
- 粒子汇聚 / 弥散
- 从一侧向主体推进的路径感
- 围绕主器官形成的柔和旋转关系

动势负责连接背景、主体和辅助元素，不应成为新的第一视觉中心。

## 3. 构图规则

### 3.1 不再固定“左 40% / 右 60%”

参考 ZIP 中的成熟 KV 并不存在唯一固定构图，因此本项目不再使用硬编码百分比构图。

允许以下成熟模式：

#### 模式 A：左留白 + 右主视觉
适合：心脏、大脑、肾脏、DNA、慢病项目、学术会议。

- 左侧或左中作为标题呼吸区
- 主医学主体集中在右侧或右中
- 流线从右下 / 下侧 / 中部连接主视觉

#### 模式 B：左主视觉 + 右留白
适合：关节、路径、规范诊疗、医学探索。

- 主体可位于左中或左侧
- 右侧保留安静区域
- 流线横向延展形成路径感

#### 模式 C：中心偏置主视觉 + 四周呼吸
适合：品牌项目、神经营养、抽象医学主题。

- 主体不是严格居中，而是轻微偏左或偏右
- 周围仍需保留明显呼吸空间
- 不允许元素平均铺满整个画面

#### 模式 D：深色科技偏心构图
适合：突破、教育、竞速、临床经验分享。

- 深蓝 / 深紫背景
- 一处高亮能量中心
- 辅助球体 / 点阵 / 流线形成节奏
- 不要同时放多个高亮主视觉

### 3.2 留白原则

无论采用哪一种模式，都必须保留一块可直接放标题和副标题的清洁区域。

这块区域不是纯白空洞，而是：

- 低对比
- 有极轻背景纹理
- 不出现高亮器官
- 不出现粗线
- 不出现密集分子 / 细胞
- 不出现强光斑
- 不出现重要人物或城市主体

也就是说：

> **底板即使暂时不加标题，也应该天然具有“可叠字结构”。**

---

## 4. 五类稳定风格方向

### 4.1 蓝白医疗留白型

适合：规范化诊疗、全病程管理、学术交流、长期项目。

视觉关键词：

- 蓝白渐变
- 高明度
- 通透
- 玻璃器官
- DNA
- 浅蓝曲面
- 微粒
- 柔和发光
- 大面积呼吸区

要求：科技感轻，不要过饱和。

### 4.2 蓝紫慢病管理型

适合：慢病管理、心脑共管、器官协同、数字医学。

视觉关键词：

- 蓝紫 / 青紫 / 粉紫
- 玻璃心脏 / 大脑 / 肾脏
- 柔和丝带
- 漂浮医学球体
- 细胞 / 药丸
- 渐变高光
- 温和未来感

要求：有未来感，但仍然保持医学可信度和洁净感。

### 4.3 粉红心血管交流型

适合：心血管、多学科交流、关怀、患者管理。

视觉关键词：

- 粉白
- 浅红
- 玫红
- 玻璃心脏
- 血细胞
- ECG
- 纤细波纹
- 透明丝带

要求：粉色应是“医学温度”，不能变成甜腻少女商业风。

### 4.4 深色科技会议型

适合：突破、竞速、医学教育、临床经验分享、创新主题。

视觉关键词：

- 深蓝 / 深紫
- 蓝绿霓虹
- 点阵漩涡
- 粒子场
- 发光医学图标
- 能量核心
- 速度轨迹

要求：只保留一个主要高亮中心，避免画面过度复杂。

### 4.5 红白规范医学型

适合：规范诊疗、风湿免疫、路径探索、临床共探。

视觉关键词：

- 白灰底
- 红橙流线
- 圆环医学结构
- 关节 / 器官图示
- 六边形医学图标
- 路径轨迹
- 淡远山 / 空气透视

要求：红色作为路径和能量强调色，不使用压迫感大面积纯红背景。

---

## 5. 生成时的硬约束

必须遵守：

- 横版主 KV，16:9。
- 优先最高原生分辨率；条件允许时使用 3840×2160。
- 不包含任何标题。
- 不包含任何文字、字母、数字。
- 不包含 logo、品牌标、医院标、水印。
- 不生成排版占位框。
- 保持明显可叠字留白。
- 主医学主体最多只有一个第一视觉中心。
- 辅助元素不能堆满画面。
- 不做左右平均对称素材陈列。
- 不做血腥解剖图。
- 不做卡通科普插画。
- 不做廉价图库素材拼贴感。
- 不做满屏 HUD / 信息图界面。
- 不让流线、粒子和装饰抢过主器官。

## 6. 默认母提示词

```text
生成一张高分辨率 16:9 医药品牌会议主 KV 底板，仅生成无文字底图，不包含任何标题、文字、字母、数字、logo、医院标志、品牌标志、水印或排版占位符。

整体必须具有成熟医药品牌会议 KV 的视觉品质：专业、现代、可信、精致、医学感明确、轻科技、品牌化，而不是科普插画、信息图、医学教材图或普通素材拼贴。

本次主医学主体为【主医学主体】。画面围绕一个明确的第一视觉中心展开。主主体采用高质量半透明 3D、玻璃质感、晶体质感、柔和发光轮廓或精细医学线框结构表达，医学结构可信但视觉包装精致，不血腥，不做硬核解剖图。

使用【辅助医学元素】作为次级视觉，仅用于增强医学语义与空间层次，数量克制，不与主主体争夺视觉中心。

整体配色采用【主色方向】。背景使用大面积低对比渐变与空气感，并结合微雾、轻波纹、纤细流线、点阵、粒子、透明弧面、柔光、能量弧或半透明丝带中的少量元素，形成“近看丰富、远看干净”的医学科技底板。

采用【构图模式】。必须保留一块明显、安静、低对比的标题呼吸区，用于后续叠加项目名称与副标题。标题区不能出现高亮器官、粗线、密集分子、强光斑或复杂主体。主视觉、流线与辅助元素集中在另一侧或偏心区域，通过自然流动关系连接画面，但不得把元素铺满整个画布。

画面需要有柔和动势，可通过 S 形流线、环抱式能量轨迹、弧形光带、透明丝带、粒子汇聚或路径推进来完成。动势只负责连接画面，不形成新的第一视觉中心。

最终效果应像成熟制药企业、医学学术会议、慢病管理项目所使用的专业主 KV 底板：有设计感、有医学语义、有空间呼吸感、可直接进入 PPT / 海报 / 会议物料后续排版。
```

## 7. 变量填写

生成时只需明确以下变量：

- `【主医学主体】`：心脏 / 大脑 / 肾脏 / 肝脏 / 肺 / 胃 / 胰腺 / 血管 / DNA / 神经元 / 关节等
- `【辅助医学元素】`：建议 2–4 类，例如 DNA、分子、ECG、细胞、药丸、血细胞、神经网络、数据粒子
- `【主色方向】`：蓝白 / 蓝紫 / 粉白 / 红白 / 深蓝科技等
- `【构图模式】`：左留白右主视觉 / 左主视觉右留白 / 中心偏置四周呼吸 / 深色科技偏心构图

如果没有特殊要求，默认优先：

- 蓝白或蓝紫医学科技
- 1 个主医学主体
- 2–3 个辅助元素
- 左侧或左中留白
- 主视觉偏右
- 轻流线 + 粒子 + 透明材质

但默认只是常用选择，不是硬性空间边界。
